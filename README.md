# RanobeLib TTS

Userscript для [ranobelib.me](https://ranobelib.me): читает вслух главу целиком — с подсветкой текущего абзаца, автопрокруткой и переходом к следующей главе.

Работает на встроенном в браузер Web Speech API, без серверов и ключей.

## Какой браузер выбрать

Качество озвучки зависит от голосов, которые браузер отдаёт странице:

| Браузер | Русские голоса | Качество |
|---|---|---|
| **Microsoft Edge** | Светлана Online (Natural), Дмитрий Online (Natural) | Нейросетевые, звучат естественно — **рекомендуется** |
| Chrome, Яндекс Браузер | Microsoft Irina, Microsoft Pavel | Системные, «роботизированные» |

Голос Алисы в Яндекс Браузере страницам недоступен — его использует только встроенная кнопка «Озвучить».

Скрипт сам выбирает лучший доступный голос (Natural → Online → остальные).

## Установка

1. Откройте браузер (лучше Edge) и установите расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Нажмите **[Установить скрипт](https://raw.githubusercontent.com/s0x7C5/ranobelib-tts/main/ranobelib-tts.user.js)** — Tampermonkey откроет окно установки, подтвердите.
3. Откройте любую главу на ranobelib.me — в правом нижнем углу появится панель.

Обновления Tampermonkey подтягивает сам из этого репозитория (при повышении `@version`).

<details>
<summary>Установка вручную</summary>

В Tampermonkey: **Создать новый скрипт** → вставьте содержимое [`ranobelib-tts.user.js`](ranobelib-tts.user.js) → **Сохранить**. Автообновление при этом тоже будет работать.

## Управление

| Действие | Как |
|---|---|
| Читать / пауза | ▶ / ⏸ или **Alt+R** |
| Предыдущий / следующий абзац | ⏮ / ⏭ |
| Остановить | ⏹ |
| Читать с нужного абзаца | **Alt + клик** по абзацу |
| Настройки | ⚙ — голос, скорость, тон, автопереход к следующей главе |

Чтение начинается с первого абзаца, видимого на экране. Настройки сохраняются в `localStorage`.

## Как это устроено

- Текст берётся из контейнера `.text-content` (плюс заголовок `h1`).
- Абзацы читаются по одному; длинные режутся на куски до ~220 символов по предложениям — Chrome иногда обрывает длинные фразы.
- По окончании главы скрипт нажимает ссылку «Вперёд» и ждёт загрузки новой главы (сайт — SPA).

Если сайт поменяет вёрстку, в первую очередь проверьте селектор `.text-content` и текст кнопки «Вперёд».
